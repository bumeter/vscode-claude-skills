# Changelog

## 0.1.0

First release.

- Status bar button **Skill Manager · 18** (installed skills in Claude Code and Kiro); click to open **Claude Skills**.
- **Installed skills** as cards: Claude Code / Kiro tabs, filter (enabled, disabled, unused for 30 days), sort by uses, name, always-on tokens or last used; a card opens to its description, tokens per session and path. Turn a skill or plugin on and off, remove it, open its SKILL.md or folder.
- **Install skill**: skills.sh as cards (Hot, Trending 24h, All time, search as you type), a git URL, or a folder.
- Every change shows what it will do first and can be undone.
- Bundles `bum`; works in remote windows (SSH, WSL, Dev Containers, Codespaces).
