# Changelog

## 0.1.0

First release.

- Status bar button with the number of installed skills (Claude Code and Kiro); click to open **Claude Skills**.
- **Installed skills** as a table: Claude Code / Kiro tabs, filter (enabled, disabled, unused for 30 days), sortable uses, projects, tokens per session, always-on tokens, last used. Turn a skill or plugin on and off, remove it, open its SKILL.md or folder.
- **Install skill**: skills.sh as cards (Hot, Trending 24h, All time, search as you type), a git URL, or a folder.
- Every change shows what it will do first and can be undone.
- Bundles `bum`; works in remote windows (SSH, WSL, Dev Containers, Codespaces).
